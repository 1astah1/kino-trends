# Сбор правил Shorts, 31.10.2026 — сырые выжимки отчётов агентов

## A3 Удержание (данные)
- Смотрели/пролистнули: <60 % почти не разгоняется, лучшие 70–90 % (Galloway 2023, 5,4 тыс. Shorts). Официальных порогов нет.
- Сообщество 09.2026 (1of10): ролики <35 с — средний % досмотра 80–90 %, сильный ≥90 %; ≥60 с — 60–75 %.
- С 31.03.2025 просмотр = любой старт/повтор; «Engaged views» = старая метрика (support 10059070).
- Рекомендации учитывают: смотрят/игнорируют, «Не интересует», длительность и %, лайки, опросы; «формат не в приоритете» (support 11914225).
- Медиана просмотров по длине (quso 06.2026, 108 тыс.): 11–20 с пик 901; 21–30 с 542; 31–45 с 347; 46–60 с 188; 90+ 51. Корреляция.
- Hoyos: лучшие 34 с; обрезка последней секунды повышает удержание; хук → намёк на развязку → поворот; первый кадр понятен без звука.
- Темп: медиана 0,33–0,37 склейки/с; в эксперименте 2026 высокий темп снижал желание досмотреть, лучше средний.
- Викторина: таймер 3–5 с (простое) / 10–15 с (сложное), ответ сразу на нуле, 0,5 с паузы = мёртвый эфир.
- Петля: конец → начало, бесшовный звук.
- Чужой материал/узнаваемая мелодия — ≤60 с (Content ID >60 с = блок по миру, support 15424877).
- При десятках показов дело в допуске к рекомендациям, не в хуке.
- Студия: кнопка «Get feedback».

## A1 Официальный алгоритм
- Новый шортс сначала тестируют на маленькой группе; дальше растёт по реакции (Шерман 2023). Решение на каждого зрителя; у Shorts своя система; учитываются время суток, устройство, что ещё смотрели (Beaupré, VidCon 06.2025).
- Опросы удовлетворённости: 4–5 звёзд = ценное время (Goodrow 2021).
- Studio: «Shown in feed» и «How many chose to view» (support 12942217). Дизлайк в Shorts убран к 06.2026, вместо него «Не интересует» с причиной.
- Провал одного ролика не штрафует канал; эксперименты с форматами не путают алгоритм; «по ссылке → открыть» не вредит; библиотека хороших роликов помогает (support 16559651).
- 24.08.2026: просмотр с первого кадра во всех форматах, engaged view = дольше первых секунд; рекомендации не менялись (блог YouTube 19.08.2026).
- Шортсы >60 с с любой заявкой Content ID — блок по миру; без штрафа каналу; снятие заявки возвращает.
- Время публикации не оптимизируется (Шерман). Удаление+перезалив = риск спама; лучше новая улучшенная версия.
- vidIQ 2026 (35 млрд просмотров): лучше 13 с и 60 с; ASMR набирает больше; у каналов от 200 шортсов рост ровнее.
- Диагностика: «Shown in feed» ≈0 на всех роликах канала = понижение канала (или блок Content ID); показы есть, «смотрели» низко = первые секунды.
- ASMR-канал = контрольная группа: если и там нули, дело не в оригинальности.

## A4 Метаданные
- Заголовок ≤100 символов; в плеере на телефоне обрезается ~40-м символом → крючок в первые 40 (vidIQ 06.2026). Точно описывать ролик; капс/эмодзи мало (support 12340300).
- Поиск: релевантность (заголовок, теги, описание, содержимое), вовлечённость, качество (support 16090438). С 01.2026 фильтр «Shorts» в поиске.
- Кликбейт: «злонамеренно вводящие в заблуждение» → удаление/страйк (2801973); кампания «грубого кликбейта» официально — Индия (12.2024).
- #Shorts не нужен (12779649). Над заголовком до 3 хэштегов; >60 → игнор всех (6390658); у трендовых в среднем 4,3.
- Теги «минимальная роль», полезны для опечаток; много тегов = спам (146402). 500 символов.
- Описание 5000 байт (кириллица ~2400 знаков). Индексируется поиском; в Shorts свёрнуто.
- defaultLanguage/defaultAudioLanguage = ru. Автодубляж с русского только на английский — выключить в Studio (ручное).
- Своя обложка Shorts с 24.07.2026 только YPP; в ленте Shorts обложки нет; A/B для Shorts нет (Test & Compare только длинные, с 09.12.2025).
- Связанное видео, закреп, кликабельные ссылки требуют «расширенных функций» (проверка по документу/видео, 9890437). Связанное видео ставится только в веб-Studio, поля в API нет (14075157).
- containsSyntheticMedia только для реалистичного (реальный человек/событие); стилизованное 3D и ИИ-голос — нет.
- Товарные знаки: не писать «официально», «от Netflix», чужие логотипы в имени/аватаре (6154218).
- Разнообразить структуру заголовка: один шаблон на сотнях роликов = inauthentic (трактовка).

## A9 Форматы, звук, техника
- Каверы/пересборка заявляются издателями по композиции (3301938) → «Угадай трек» на известной мелодии = ожидаемая заявка; держать <60 с. Без заявки — только своя мелодия или Audio Library.
- Сдвиг тона/скорости — неприемлемо в монетизации и «уход от распознавания» в спам-правилах.
- Не монетизируется: «клипы моментов шоу с минимальным сюжетом», «слайд-шоу, шаблонные сюжеты, бегущий текст с минимальным сюжетом или комментарием». Разрешено: сцена с переписанным диалогом и новой озвучкой; ремикс с добавлением своего (1311392).
- Тренды YouTube 2025: ценят «существенные человеческие усилия»; растут невербальные шортсы; аниме-фандомы.
- Кодирование (1722171): H.264 High, 4:2:0, 2 B-кадра, закрытый GOP = fps/2, VBR 8 Мбит/с (1080p ≤30 fps) / 12 (60 fps), faststart, BT.709, AAC-LC 48 кГц 384 кбит/с. Частоту кадров не менять.
- Безопасная зона (Google Ads, 1080×1920): сверху 288, снизу 672, слева 48, справа 192 → полезная 840×960 (x 48–888, y 288–1248). Для обычных роликов официальных цифр нет; сторонние: сверху 120–288, снизу 300–480, справа 96–192.
- Громкость −14 LUFS / −1 dBTP; YouTube тише не поднимает → нормализовать киноисходники.
- Super Resolution с 30.10.2025 для <1080p. Качество влияет только через удовлетворённость.
- Текст вместо голоса: «бегущий текст с минимальным сюжетом» назван прямо; голосовой комментарий скорее одобрен, если это комментарий, а не пересказ.

## A2 Политики
- Reused (1311392): применяется к каналу целиком; можно, если «viewers can tell that there's a meaningful difference». Разрешено: критический обзор, переписанный диалог + новая озвучка, реакция с комментарием, чужое + сюжет и комментарий. Запрещено: «Clips of moments … with little or no narrative», перезаливы, песни с изменённой высотой/скоростью. Даже с разрешением правообладателя.
- Inauthentic: шаблонные сюжеты; слайд-шоу и бегущий текст без нарратива; «characters put in the same situation over and over again with the same outcome»; шаблонный массовый ИИ. Разрешено: одинаковые интро/аутро при разном основном содержании; серия, если у каждого ролика своя идея.
- Спам (2801973, удаление и страйки): «automated tools or AI to churn out high volumes of similar content with minimal changes» («a few variations is ok»); scraped content без «original commentary, educational value, or unique editing»; detection evasion (ускорение, фильтры, кроп, зеркало); «Off-platform diversion» — ролик «solely to drive users off of YouTube»; распространяется на «coordinated networks of channels». 3 страйка за 90 дней = удаление.
- Удаление канала (2802168): за один тяжёлый случай спама; запрет на все существующие и новые каналы владельца → много одинаковых каналов = выше общий риск.
- Content ID <60 с: политика правообладателя (блок/монетизация/отслеживание, по странам). Немузыкальный чужой контент в Shorts правообладателю денег не даёт → блоки и ручные страйки.
- Музыка: аудиотека Shorts — особая заявка без блока; Audio Library — без заявок; каверы = композиция.
- ИИ-метка (14328491): обязательна для реалистичного и для «AI generated music» / «music that's the main focus». Не нужна: анимация, ИИ для сценария/заголовков/субтитров. «Disclosing AI content alone won't limit a video's audience». Голос похож на реального человека — раскрывать.
- Платное продвижение (154235): branded content/спонсорство; про свой продукт молчит; API paidProductPlacementDetails.hasPaidProductPlacement.
- Применимо: в каждом ролике с чужим — видимая своя ценность (мнение, разбор, факт вне сцены, сюжет из нескольких кусков); тексты различаются по смыслу, разные рубрики; потолок выпуска и отсев почти одинаковых; ролик ценен сам по себе, не только ради перехода.

## A5 Практика загрузки
- Частота сама по себе не ранжирует, минимального темпа нет (11914225; Beaupré 09.2026). Shorts конкурируют с чужими, не со своими. Шаблонность оценивается по каналу целиком («repetitive after several videos in a row from the same channel»).
- Время публикации не приоритет (Шерман 2023); Buffer 2026: пик пт 16–19, вечера 18–23 местного, но для Shorts менее решающе.
- publishAt только при private и ни разу не публиковался. По ссылке → публичный не вредит. Публичный в приватный не переводить (Beaupré 03.2024).
- API vs приложение: официально не различаются; разница только в звуках из аудиотеки.
- Холодный старт: «critical mass of content»; первые сотни–тысячи показов — разведка. Расширенные функции: история ~2 мес без нарушений или документ/видео.
- «long-term channel performance can be affected», если зрители стабильно не смотрят рекомендованные ролики канала (16559651).
- Не удалять (теряется связь с аудиторией, Beaupré 2024); не перезаливать провал; `rejectionReason=duplicate`; «posting the same content repeatedly across one or more channels» отнимает расширенные функции (9891124).
- Правка заголовка может сдвинуть показатели; не менять то, что работает.
- Каналы: лимита нет; бан за спам — на все каналы владельца; «coordinated networks of channels». Телефон — до 2 каналов в год.
- Конвейер: новому каналу без проверенного формата 1–2 в день, 4 — только где «решили посмотреть» уже хорошее; судить через 7–30 дней.

## A8 Аналитика и API
- Studio: «Показано в ленте» и «Решили посмотреть» (12942217) — В API НЕТ ни того, ни другого.
- Analytics API: views, engagedViews, averageViewDuration, averageViewPercentage, likes, shares, subscribersGained; удержание audienceWatchRatio, relativeRetentionPerformance (0–1, 0,5 = медиана роликов той же длины); creatorContentType=SHORTS; insightTrafficSourceType=SHORTS. Задержка 48–72 ч. Удержание — один ролик за запрос.
- Reporting API: channel_basic_a3, channel_traffic_source_a3 (traffic_source_type=24 Shorts), хранение 60 дней.
- Квота: с 01.06.2026 videos.insert — своя корзина 100 вызовов/сутки на проект; остальное 10 000 ед. uploadLimitExceeded = лимит канала, пауза 24 ч.
- Через API видно: uploadStatus, rejectionReason (claim, copyright, duplicate…), regionRestriction allowed/blocked. Обычная заявка без блока не видна.
- Пороги (предложение агента): ворота распространения — 5+ шортсов разных тем подряд с viewCount <30 за 48 ч → ограничение канала/класса, не формата; крючок engagedViews/views по SHORTS ≥0,7 хорошо, <0,5 плохо; APV ≥80 % (<35 с), ≥60 % (≥60 с); relativeRetentionPerformance ≥0,5; <100 engagedViews = нет данных; решение по когорте 8–12 роликов.
- Metricool 07.2026: >61 % органики из ленты Shorts; лучший результат на ролик при 2–4 Shorts в неделю; с хэштегами ~на 10 % меньше (корреляция).
