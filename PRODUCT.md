# Kino Trends — продукт

Внутренняя консоль оператора конвейера Shorts (проект auto-shorts). Отвечает на вопрос:
какие фильмы и сериалы режут на YouTube Shorts для русскоязычной аудитории, насколько это заходит
(просмотры, скорость набора, насыщенность конкурентами) и какие форматы оформления работают.

## Кто и где
Один оператор (владелец), сидит в VS Code с проброшенным портом, тёмная тема редактора, вечер.
Открывает консоль несколько раз в день перед тем, как выбрать материал для нарезки.
Предположение (не подтверждено владельцем): смотрит с ноутбука, иногда с телефона.

## Задача (режим Operate)
1. За 10 секунд увидеть, что сейчас набирает: топ произведений за период, свежие, «мало конкурентов».
2. Провалиться в произведение: какие ролики, какие каналы, какие хэштеги и длительность, динамика по дням.
3. Понять «что заходит по интересам»: жанры, страны, типы (фильм, сериал, аниме), длительность, приёмы заголовка.
4. Довести данные: разметить неопознанные ролики (поиск по словарю, новый тайтл), научить словарь.
5. Управлять сбором: хэштеги, каналы, расписание, ключ Data API, журнал прогона, экспорт CSV.

## Правда о данных
- Источник: публичные страницы YouTube (хэштеги, вкладки Shorts каналов, страницы роликов, RSS), словарь Wikidata.
- Просмотры со страниц хэштегов и каналов округлены; точные — со страницы ролика, RSS и Data API.
- Лайки и комментарии есть не у всех роликов (без ключа Data API — только из RSS последних 15 роликов канала).
- Распознавание автоматическое, с уверенностью 0..1; порог включения в статистику настраивается (по умолчанию 0,6).

## Границы
- Никаких внешних ресурсов во фронте: системные шрифты, без CDN. Миниатюры через прокси сервиса.
- Русский язык интерфейса, идентификаторы латиницей.
- Один пользователь на localhost, без авторизации.
